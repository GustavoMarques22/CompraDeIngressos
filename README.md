# 🎟️ e-Ticket — Sistema de Venda de Ingressos

Bem-vindo ao **e-Ticket**, uma aplicação web simples e dinâmica para venda e controle de ingressos online!
Desenvolvido com **HTML**, **CSS** e **JavaScript**, o sistema permite comprar ingressos de diferentes setores com controle de estoque em tempo real.

## 🚀 Funcionalidades

* ✅ Compra de ingressos para 3 setores: *Pista*, *Cadeira Superior* e *Cadeira Inferior*.
* ✅ Validação automática da quantidade disponível antes da compra.
* ✅ Atualização dinâmica no estoque sem recarregar a página.
* ✅ **Resumo do carrinho** salvo no navegador (usando localStorage).
* ✅ Interface moderna e responsiva.

## 🖥️ Tecnologias Utilizadas

* **HTML5** — Estruturação semântica.
* **CSS3** — Estilização com design responsivo e moderno.
* **JavaScript (Vanilla)** — Manipulação do DOM, lógica de negócio e armazenamento no localStorage.

## 🎯 Como Usar

1. **Baixe ou clone** este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Escolha o tipo de ingresso e a quantidade desejada.
4. Clique em **Comprar** e veja o estoque ser atualizado.
5. Confira seu carrinho atualizado na tela!

## 🛒 Extras (Bônus)

* 💾 As compras ficam **salvas** no navegador mesmo após fechar a página.
* 🔒 O sistema impede comprar mais ingressos do que a quantidade disponível.
* 💡 Pode ser evoluído facilmente para incluir botão de "Finalizar Compra" ou "Limpar Carrinho".
